# NAVIS Browser (Native Android APK Project)

## One-Click Automated APK Build via GitHub Actions (No Local Android Studio Required)
1. Create a new repository on GitHub (for example `navis-browser-android`).
2. Upload the contents of `NAVIS-Browser-Android` (including the `.github/workflows/build-apk.yml` file).
3. Go to the **Actions** tab in your GitHub repository and run **Build NAVIS Browser APK**.
4. Once the workflow finishes, download **`app-debug.apk`** from the **Artifacts** section and install it directly on your Android phone.
